### Quick Summary

**SkillMatchAI** is a micro-learning platform that uses **Google Gemini AI** to create personalized learning plans and adaptive educational content. The platform generates custom content based on user goals, learning styles, and performance.

**Key Technologies:**
- ✅ **LLM (Large Language Model)**: Extensively used (Google Gemini 2.5 Flash/Pro)
- ❌ **RAG (Retrieval-Augmented Generation)**: Not currently implemented
- 🚀 **Next.js 15** + **React 19** + **TypeScript**
- 🗄️ **Supabase** (Database & Auth)
- 🎨 **Tailwind CSS** + **Radix UI**

## 🤖 AI Features

This platform leverages Google Gemini AI for:

- **Personalized Learning Plans**: Automatically generates custom learning paths
- **Adaptive Content**: Creates module content tailored to learning styles
- **Student Evaluation**: AI-powered assessment and feedback
- **Progressive Difficulty**: Adjusts challenge level based on performance

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies: `pnpm install`
3. Set up environment variables (Supabase, Google AI API keys)
4. Run development server: `pnpm dev`
5. Open [http://localhost:3000](http://localhost:3000)
